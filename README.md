# Customer Churn Prediction Dashboard

🔗 **Live demo:** https://customer-churn-prediction-dashboard-wtp7d5kzjgtkidurvvodxt.streamlit.app/

A Streamlit dashboard that predicts whether a customer is likely to churn, using an XGBoost model.

## Features
- Enter customer details and get a churn prediction
- Model trained on customer data with scikit-learn preprocessing

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech stack
Python, Streamlit, pandas, scikit-learn, XGBoost etc.
